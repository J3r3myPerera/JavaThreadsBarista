# JavaThreadsBarista
Creating a simple implementaion of a coffee shop with the use of Java Threads

In this execution a the concept of a Java monitor is being used with level synchronization. I have implemented this to demonstrate the Java concurrency.
The shared resource will be a queue where the customer who is placing the order and also the barista who is making the coffee will be accessing in a mutual exclution manner.
Using a Java IDE you can run this in any background. I use IntelliJ IDEA CE for my developmenmt and testing.
Try with changing the max number in the queue and see who it will give the output.
Feel free to contribute to this with any modifications. This is just a basic idea I have done for my course work in university.
